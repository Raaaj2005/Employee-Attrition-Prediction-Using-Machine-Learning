# 🧑‍💼 Employee Attrition Prediction Using Machine Learning

## 📖 Overview
This project applies machine learning to human resources (HR) analytics by predicting employee turnover. By analyzing workforce data, the notebook guides you through the complete data science pipeline—from importing and exploring HR datasets to cleaning the data, performing feature engineering, and ultimately training a Logistic Regression model to identify key factors that lead to employee attrition.

## 🎯 Objective
The primary objective is to build a binary classification model capable of accurately predicting whether an employee is likely to leave the company. By leveraging Logistic Regression, the project aims to uncover patterns in employee data—such as job satisfaction, salary, and department—to assist organizations in developing proactive retention strategies.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Machine Learning:** Scikit-Learn (Logistic Regression)
* **Data Manipulation & Visualization:** pandas, NumPy, Matplotlib, Seaborn

## 🧠 Key Learnings & Skills Demonstrated
* **Problem Formulation:** Understanding the business impact of employee attrition and framing the predictive classification task.
* **Exploratory Data Analysis (EDA):** Visualizing HR datasets to uncover trends, distributions, and correlations related to employee turnover.
* **Data Cleaning & Preprocessing:** Handling missing values, scaling numerical features, and encoding categorical variables (like department and job role) for machine learning ingestion.
* **Model Training:** Implementing and fitting a Logistic Regression classifier to predict the binary outcome of attrition.
* **Model Evaluation:** Assessing model performance using key classification metrics such as accuracy, precision, recall, and analyzing the confusion matrix.

## 🚀 Getting Started

### 📋 Prerequisites
To run this project, you will need:
* Python 3.x
* Jupyter Notebook or JupyterLab

### ⚙️ Installation & Setup

1. Clone the repository to your local machine:
   git clone https://github.com/Raaaj2005/Employee-Attrition-Prediction-Using-Machine-Learning.git

2. Navigate into the downloaded project folder:
   cd Employee-Attrition-Prediction-Using-Machine-Learning

3. Install the required dependencies:
   pip install pandas numpy scikit-learn matplotlib seaborn jupyter

4. Launch the Jupyter Notebook environment:
   jupyter notebook

5. Open the project's .ipynb file and execute the cells sequentially to perform the HR analysis and train the predictive model.
